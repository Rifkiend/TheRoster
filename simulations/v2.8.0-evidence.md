## Angka ambang (lokal + GitHub)

- Lokal (8 repo, 3–225 file): graph hemat 74,4%–99,0% di semua repo di atas ambang; titik balik per-file ~140–190 token.
- GitHub (5 repo publik, clone shallow read-only): tokenize-rt (14 file / 852 baris) hemat baterai 88,3%; retrying (12 / 1.303) 84,5%; requests (97 file) 95,7%. Titik balik per-file ~210–225 token; **gabungan ~140–230 token**. Tidak ada repo GitHub yang jatuh ketat di bawah ambang (repo GitHub selalu membawa file metadata) — pita 5–10 file / 500–1.000 baris tetap belum terukur ketat; kotak di bawah ambang belum ada datanya di GitHub.
- Repo non-Python: graph menjawab ukuran/dir dengan hemat besar (express J1 file terbesar 98,1%, J2 direktori `test/` 92,4%) tapi NOL untuk simbol/links/owner (tidak ada parser JS). Repo mungil escape-string-regexp (11 file / 148 baris): SEMUA file kode kalah lawan record-nya — contoh paling murni kenapa ambang ada.
- **Ambang direkomendasikan tetap: file < 5 DAN baris < 500 (AND).** Tidak perlu revisi dari uji GitHub.
