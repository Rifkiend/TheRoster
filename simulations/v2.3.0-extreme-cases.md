## Yang masih TIDAK teruji

- Git < 2.38 di MESIN NYATA (bukan shim): jalur fallback teruji lewat shim
  PATH yang memalsukan `git merge-tree` gagal (exit 128) — log shim
  membuktikan trial-merge benar-benar jalan (E6). Tapi perilaku git tua
  yang sesungguhnya (mis. `git worktree add` versi lama, `merge-tree`
  yang tidak ada SAMA SEKALI) belum dijalankan di mesin dengan git < 2.38.
- Worktree di mesin lain yang BENAR-BENAR ada (E7 hanya menguji path yang
  tidak ada di mesin ini — perilaku skip+note terverifikasi, tapi tidak ada
  mesin kedua yang membuktikan klaim lintas-mesin itu nyata).
- Konflik SEMANTIK (dua worktree merge bersih tapi saling merusak — mis.
  rename fungsi di satu sisi, pemanggil baru di sisi lain): merge check
  bersifat tekstual; desain sudah mengakui ini sebagai batas yang diketahui.
- Skala: puluhan worktree sekaligus (kinerja merge-tree per klaim, dan
  perilaku `git worktree list` saat ada worktree yang rusak/pruned).
